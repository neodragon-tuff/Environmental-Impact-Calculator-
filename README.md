# Environmental Impact Calculator

A small, single-file interactive calculator that estimates your annual carbon footprint from six quick questions (home energy, transportation, air travel, diet, shopping, and waste) and shows how it compares to the global average and the 1.5°C target.

**[View it live](#)** — once GitHub Pages is enabled, replace this link with your Pages URL (see setup below).

## Files

- `index.html` — the entire app: HTML, CSS, and JavaScript in one self-contained file. No build step, no dependencies to install.

## Running it locally

Just open `index.html` in any browser. Double-click it, or run:

```bash
open index.html      # macOS
start index.html      # Windows
xdg-open index.html   # Linux
```

## Hosting it for free with GitHub Pages

1. Push this repo to GitHub (see the main instructions you were given).
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Pick the **main** branch and **/ (root)** folder, then **Save**.
5. GitHub will publish the site at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Notes

The emission estimates used are rough, illustrative averages (not a certified carbon audit) meant to give a directionally honest picture of where a footprint comes from.
